Preparar la instalación

Este archivo permite copiar el código a Google Apps Script. Funciona sin conexión; no carga ni envía datos. El README contiene la guía completa.

  1. Crear una Google Sheet vacía y abrir Extensiones → Apps Script.
  2. Crear los archivos .gs como secuencias de comandos y los .html como archivos HTML. Copiar su contenido desde el selector inferior.
  3. Mostrar el manifiesto desde Configuración del proyecto y reemplazar appsscript.json.
  4. Ejecutar inicializar_ y autorizar. Para una base de demostración vacía, ejecutar también datosFicticios_.
  5. Compartir la Sheet con las cuentas del equipo, configurar ALLOWED_EMAILS y desplegar como Web App ejecutada por la usuaria que accede.
  6. Distribuir la URL /exec. Validar la instalación con VALIDACION.md.
Incluye código, README y pruebas locales sin dependencias.
